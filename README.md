\# CrackVision



\## Structural Crack Detection and Monitoring System



CrackVision is a web-based system designed to detect and monitor visible cracks in structures such as buildings, walls, bridges, columns, and beams.



\## Technology Stack



\- Frontend: React + Vite

\- Backend: Spring Boot

\- Database: Aiven Cloud MySQL

\- Authentication: JWT

\- Authorization: Role-Based Access Control

\- AI Service: Python Computer Vision

\- Containerization: Docker

\- Version Control: Git + GitHub



\## Main Modules



\- User Authentication

\- Role-Based Access

\- Project Management

\- Building/Floor/Component Management

\- Structural Image Upload

\- Crack Detection

\- Crack Severity Classification

\- Engineer Review

\- Crack Monitoring

\- Inspection History

\- Reports

\- Admin

\- Site Worker
